本项目仍按已确认要求增加释放/退开、稳定2秒及配置化几何/速度门槛。这里不复制其任务环境或引入整套robosuite。

示教规划使用独立配置与只读快照，执行仍经公共控制入口，测量来自真实物理步进。

两个链接是核对时的上游分支，可能继续变化；若后续直接吸收代码，应先固定commit与许可，
记录来源和修改。本轮仅核对思路，没有复制源码或把上游示例当成本场景的验收证据。

## S4实施时必须补的本项目证据

- 静态已堆叠、未释放、侧碰、掉落和未退开等正反例；不能只以高度、接触或夹爪开度单项判成功。
- 使用真实物理接触、物体几何和速度，连续按仿真时间计稳定时长；停钟有墙钟故障保护。
- 程序示教可读物体真值；策略特征保持三RGB与16维测量位置，任务判定不作为补救动作来源。
- 完整动作链路、三相机视野、参考/测量和失败原因留证；所有完整堆叠试采进入最多10次试采账本。
- 几何与速度数值最终放入成功判定配置，后续按实测验证，不在训练或评估脚本里临时改阈值。
