## 固定20次真实闭环评估

种子20000～20019全部计入，使用同一5000步模型。无重复、替换或缺失结果。

- 可信ACT执行20/20，重复观测与预测闭环20/20；每例实际执行19～56个动作块。
- 物理堆叠成功0/20，完整运行成功0/20。20次均因`FOLLOWER_DEVIATION_EXCEEDED`结束；这是实际控制失败，不能记为任务通过。
- 录制完整20/20；每例原始预测、准入目标、实际参考、实测反馈和失败原因均保留。
- 图像质量15/20合格。20002、20008、20010、20015、20018的右腕目标可见性未达门槛；不因此从成功率分母剔除。
- 每例预测延迟P95为21.284～32.434ms。该值是模型请求耗时，不等于整个控制链路的时延。
- 生成20段三视角预览与60张关键帧；所有本轮所属容器和网络已清理。

独立物理结果与运行、录制、图像质量分别报告。正式数据来自程序teacher；ACT运行不读取物体真值、不使用IK或teacher补救，也不覆盖左臂预测。

用户批准的夹爪准入仅将左右总开度限制到0～0.08m，单次修正最多0.03m，超过拒绝；机械臂保持严格规则。原始ACT输出和准入值分别保存在`act-policy-log/predictions/*.npz`。最终64个离线观察全部通过这一准入，最大修正0.029202m，机械臂值不变；这不代表预测精度得到改善。

两次ACT pilot启动失败1008/1009分别暴露公共入口源码路径和runtime SDK挂载遗漏，已做最小修复及回归检查，失败仍计台账。总pilot9/10，不另开空台账重置预算。
