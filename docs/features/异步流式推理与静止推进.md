# 真正异步推理与时序不变静止推进

本文档定义策略闭环流式执行（`PolicyStreamRunner`）的异步推理、时序不变静止推进与边界精简设计。

> **状态区分（文档内标注）**
> - **本轮落地**：后台真正异步推理线程、绝对时间戳有效帧缓存（时序不变 + 新值优先）、整窗原子回退、清理阻塞式伪异步与时间轴前移补丁；保留后端 ACK、Ruckig 插值/限位/平滑、协同轴组可达包络重定时、启动预热与按轴微幅硬限位投影。
> - **后续期望落地**：更细粒度的短执行窗/自适应重规划周期、支持真正多模型历史上下文的流式服务协议扩展。

---

## 1. 功能定位与职责边界

- **所属层**：通用运行端（`runtime/ros2/ros/dual_arm_runtime/dual_arm_runtime/chunk_stream.py`），100% 机器人/任务无关，不得硬编码任何方案名或物块尺寸。
- **核心设计不变量**：
  1. **时序不能变（Timeline Invariance）**：任何预测点的绝对仿真时间戳 `t_abs = t_obs + (i + 1) * P` 严禁前移或篡改。若 `21 s` 预测的 `21..24 s` 中前 `1 s` 为静止帧，剥离前导静止帧后，剩余有效动作仍严格归属 `22..24 s`，绝不强行搬移到 `21..22 s` 破坏物理稳定保持期。
  2. **新值优先（Newest-Observation Priority）**：只要更新观测 `t_obs_new > t_obs_old` 在目标执行窗内给出有效动态动作，一律优先采用新预测，丢弃旧预测在同一时刻的值；仅当最新预测在目标窗口内全静止（单帧无记忆死锁）时，才按原绝对时间戳回退到最新包含有效动态点的历史预测。
  3. **最小必要机制（去模型耦合）**：运行端不保留与特定策略分布或旧同步模式耦合的补丁（如时间轴前移 `_advance_stalled_window` / `_late_gripper_onset`、时间融合 `TemporalEnsemble`），只保留与模型无关的工程底线。

## 2. 本轮落地实现

### 2.1 线程模型与数据流（真正异步）

```text
观测流 obs(t) ──▶ [后台异步推理线程 Producer] ──▶ 按 t_obs 递增写入有限历史预测环 (带绝对时间戳)
                        │ (跳过积压旧帧，始终对最新 obs 发 Predict RPC)
                        ▼
主循环 Consumer ──▶ get_anchor() 拿到固定交接锚点 H_{k+1}
               ──▶ 等待仿真时钟到达 H_{k+1} - prefetch_lead_ns（提交前余量）
               ──▶ 从缓存按绝对时间窗口 [H_{k+1}+50ms .. H_{k+1}+1.0s] 选窗（新值优先 + 静止回退）
               ──▶ 经通用运动学可达包络重定时 (transition_retiming) ──▶ submit_follower + ACK
```

- **Producer（后台推理线程）**：
  - 独立于主提交循环持续拉取最新 `ExactObservation`；若上次 RPC 期间已产生多帧新观测，只对最新帧发起一次 `Predict` RPC，不积压、不阻塞主循环。
  - 首块在启动稳定等待与预热（`startup_settle` + `warmup_on_settle`）完成后启动；任务终止、停止信号或异常发生时立即置错并安全回收线程。
- **前导静止剥离与缓存结构（`AsyncPredictionBuffer`）**：
  - 每条预测记录 `(observation_id, observation_time_ns, targets_60, active_from_index)`：
    - 扫描 60 点轨迹，计算前导连续静止段结束位置 `active_from_index`（静止判定仅基于机器人关节物理单位的通用小死区：臂轴 `rad` 变化 `< 0.015 rad`、夹爪 `m` 变化 `< 0.002 m`）。
    - 保留最近若干条（如 8 条，覆盖 3 s 预测跨度）已完成预测，不改写其中任何点的 `t_abs`。
- **Consumer 整窗原子选窗规则（针对目标执行区间 `(H_{k+1}, H_{k+1} + W]`）**：
  1. 取最新已完成的预测 `P_latest`，按绝对时间戳筛出 `(H_{k+1}, H_{k+1} + W]` 对应的 `target_count` 个点；
  2. 若 `P_latest` 在该窗口内**非静止**（相对 `anchor.reference` 或窗内首点存在超过死区的运动）→ **整窗直接使用 `P_latest`**（新值优先，单窗内无拼接跳变）；
  3. 若 `P_latest` 在该窗口内**全静止** → 按 `t_obs` 从新到旧检索缓存中的历史预测 `P_prev`，寻找第一个**完整覆盖 `(H_{k+1}, H_{k+1} + W]` 且在该窗口内非静止**的 `P_prev`：
     - 找到 → 使用 `P_prev` 在**同一绝对时间戳 `(H_{k+1}, H_{k+1} + W]`** 处的目标点，向后端提交时仍绑定当前新鲜观测的 `observation_id / observation_time_ns` 以维持 `max_observation_age_s` 断流活性校验，并记录结构化事件 `policy.wait_advance_applied`（携带 `source_observation_id` 与 `current_observation_id`）；
     - 若所有历史预测在该窗口内均静止 → 整窗采用 `P_latest` 保持静止。

### 2.2 保留与移除的推理机制边界

| 类别 | 机制 | 归属 | 处置与理由 |
| :--- | :--- | :--- | :--- |
| **保留不动** | ACK 应答、控制租约、幂等查询 | `runtime` / `simulation` | 通信可靠性与单写者控制权底线 |
| **保留不动** | Ruckig 插值、速度/加速度/硬限位、平滑与可刹停检查 | `simulation/common` | 物理安全执行底线 |
| **保留不动** | 可达包络与同臂协同轴组等比例重定时（`transition_retiming.py`） | `shared/common` | 纯运动学物理可达性约束，与模型无关 |
| **必要保留** | 启动稳定等待与首帧预热（`startup_settle` + `warmup_on_settle` + `OpenSession` warm-up） | `runtime` / `learning` | 消除首帧 CUDA JIT `300–500 ms` 延迟尖峰，预热后单次 `Predict` 稳定在 `21–30 ms` |
| **必要保留** | 按轴微幅硬限位投影（`max_prediction_corrections`） | `learning` | 裁剪模型线性输出头在硬限位边缘的 `1e-4 ~ 5e-3` 数值微过冲，避免无谓整块拒收 |
| **本轮移除** | 阻塞式伪异步 `_predict_executor` | `runtime/chunk_stream.py` | 原实现提交单次任务后原地死等，替换为真正后台持续异步推理线程 |
| **本轮移除** | `_advance_stalled_window` / `_late_gripper_onset` / `_shift_window` | `runtime/chunk_stream.py` | 原实现会前移时间戳改写时序，已被时序不变的历史非静止整窗回退替代 |
| **本轮停用** | `TemporalEnsemble`（时间融合） | `learning` | 保持 `temporal_ensemble_coeff: null`，避免历史加权拖慢实时响应 |

## 3. 后续期望落地

1. **数据源头去空等后的更短提交提前量**：当 Teacher 采集侧进一步压缩航点间无用空等后，可将 `prefetch_lead_ns` 收缩至 `100–200 ms` 区间，在保持 `min_lead_s = 50 ms` 安全裕量的同时把观测滞后进一步压低。
2. **多帧/状态化策略流式协议兼容**：当模型端引入 `n_obs_steps >= 2` 或历史隐状态时，后台生产者需按观测序维护会话输入队列，保证跨帧特征连续。
3. **动态短窗执行验证**：在当前 1.0 s 窗口稳态基础上，后续可评估 `0.25–0.5 s` 执行窗与异步推理的匹配收益。
