## 编写规范

- **文件命名**：除索引文件 `README.md` 外，统一使用简短清晰的中文主题名（如 `异步流式推理与静止推进.md`、`精准静止锚点过滤.md`），一个独立完整的功能对应一篇文档。
- **与实现同步**：文档内须清晰区分已落地实现与后续规划，参数值以配置文件和 Schema 为唯一数据源（SSOT），不在文档中维护冗余副本。
- **结构建议**：
  1. 功能定位、适用场景与职责边界（含状态区分）。
  2. 参与模块、核心流程、状态机与线程/资源所有权。
  3. 输入输出、通信契约（ROS 2 / gRPC）、物理单位与时序约束。
  4. 源配置文件、运行入口与验证测试方法。
  5. 常见错误码、故障表现与后续演进方向。
