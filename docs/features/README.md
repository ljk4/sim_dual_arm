# 功能说明索引

本目录按核心功能模块组织设计说明，描述系统的职责划分、跨模块协作流程、通信契约与使用边界，帮助开发者从具体能力快速定位代码与配置。

## 编写规范

- **文件命名**：使用简短的英文主题名（如 `action-execution.md`、`act-training.md`），一个独立完整的功能对应一篇文档。
- **与实现同步**：文档仅描述当前已实现的能力与边界，参数值以配置文件和 Schema 为唯一数据源（SSOT），不在文档中维护冗余副本。
- **结构建议**：
  1. 功能定位、适用场景与职责边界。
  2. 参与模块、核心流程、状态机与线程/资源所有权。
  3. 输入输出、通信契约（ROS 2 / gRPC）、物理单位与时序约束。
  4. 源配置文件、运行入口与验证测试方法。
  5. 常见错误码、故障表现与已知限制。
