# 多爪负载转移通用守卫

本文档记录多夹爪协作任务中“防止负载尚未交稳即提前卸载”的分层设计：明确当前任务评价器侧与策略训练侧已落地能力，以及面向任意多夹爪机器人的零魔数通用守卫演进路径。

> **状态区分（文档内标注）**
> - **本轮已落地**：
>   - 通用重定时层保持 100% 方案无关，不包含任何物块尺寸硬编码魔数；
>   - Marvin 交接任务评价器（`marvin_sim/handover/evaluator.py`）细化移交边界（`in_handoff_transfer` 与 `_holder_required` 仅在左手开始释放后严格要求右手持续持物，并在左手连续持物期间动态刷新双持参考位姿）；
>   - 训练侧通过 `sample_filter` 抽稀冗余等待锚点，保留双持与释放阶段的稳态训练样本。
> - **后续期望落地**：
>   - **L1（通用受载-闭合运动竞态守卫）**：零任务名、零物块尺寸魔数的通用物理判据守卫，作为可选开关供多夹爪机器人启用；
>   - **L3（观测契约升级）**：在通用观测中引入末端夹爪负载特征（力/电流）或多帧历史上下文（`n_obs_steps >= 2`），从感知层面彻底消除单帧位置观测的抓持状态歧义。

---

## 1. 架构隔离原则

通用轨迹重定时层（`shared/common/python/trajectory/src/robot_trajectory/transition_retiming.py`）必须保持 100% 机器人/任务无关，严禁引入绑定特定物块宽度（如 `60 mm`）的夹爪开度阈值或左右手角色假设：
- 与具体任务移交语义相关的判定归属对应任务插件（如 `simulation/mujoco/src/robot_backend_sim/marvin_sim/handover/evaluator.py`）；
- 与任意多夹爪机器人通用的运动学/物理安全机制才允许进入 `shared/common/` 或 `runtime/ros2/`。

---

## 2. 本轮已落地实现

1. **任务级交接过渡边界（`marvin_sim/handover/evaluator.py`）**：
   - 在左手仍稳定持物（`left_holding`）且尚未进入释放前，允许右手在双持阶段微调夹紧力度而不被误判为 `HOLD_LOST`；
   - 当左手持续空中持物期间右臂完成对准建立双持时，动态刷新双持参考位姿（`_dual_left_reference_refreshed`），消除对齐前微小位姿漂移导致的虚假失稳判定；
   - 回归验证位于 `tests/unit/test_handover_task.py`。
2. **训练锚点过滤**
   - Handover 的 `full` 训练抽稀符合静止条件的 `WAITING_FOR_FEEDBACK` 等待段内部锚点，保留双持与释放阶段的稳态样本以及阶段切换前后的锚点。[精准静止锚点过滤](精准静止锚点过滤.md)

## 3. 后续期望落地：深层通用演进路径

### 3.1 L1：受载爪—闭合爪运动竞态守卫（零魔数、纯物理判据）

**适用范围**：任意具备 2 个及以上末端夹爪（`joint.unit == "m"`）的机器人，无需声明任务类型、物块尺寸或左右手角色。

**通用物理判据**（同时满足三条即判定存在负载转移竞态）：
1. **夹爪 `A` 处于受载夹持态**：闭合方向控制参考持续小于实测开度（`q_ref[A] < q_meas[A] - load_gap_tol`，表明两指受物体阻挡并施加夹持预载），或消费底层通用接触/力矩反馈；
2. **另一夹爪 `B`（`B != A`）处于闭合行进未稳态**：本窗口目标要求 `B` 显著闭合（`q_target_end[B] - q_start[B] < -close_step_tol`）或继承速度仍在闭合（`v_anchor[B] < -close_vel_tol`）；
3. **本窗口要求 `A` 同步释放**：目标要求 `A` 显著张开（`q_target_end[A] - q_start[A] > +open_step_tol`）。

**守卫动作**：仅将 `A` 的释放延后一个执行窗（维持 `A` 当前闭合参考，不修改 `B` 的闭合轨迹）并记录审计事件；单手任务中判据 2 恒为假，零触发、零侵入。

### 3.2 L3：感知与观测契约升级

单帧关节位置观测 `observation.state = qpos` 无法区分“空抓闭合途中”与“已接触物体并施力夹稳”。长期通用升级方向（涉及跨端契约与重采，须经用户确认后实施）：
1. 在 `RobotState` 与观测 Schema 中可选暴露通用末端夹爪力矩/法向接触力或驱动电流特征；
2. 在学习端与运行端支持短历史观测帧堆叠（`n_obs_steps >= 2`）或引入关节速度特征，由策略自身从时序动态判别抓持稳态。
