# 多爪负载转移通用守卫（双爪互锁的通用演进）

本文档记录多夹爪机器人协作任务中“防止负载尚未交稳即提前卸载”的深层通用设计思考，明确排除与具体任务/物块尺寸强耦合的硬编码规则。

> **状态区分（文档内标注）**
> - **本轮落地策略（L2 治本优先，不在执行侧加耦合补丁）**：本轮不把历史 `6ba0f73` 中含 `0.056 / 0.060 / 0.068 m` 毫米魔数的 `other_closing` 写回公共重定时层；优先通过精准 `sample_filter`、视觉平移鲁棒增强与真正异步推理从策略自身根治误松手，并通过实测验证是否仍有负载转移竞态。
> - **后续期望落地（按需分两层演进）**：
>   - **L1（通用物理/运动学安全守卫）**：零任务名、零物块尺寸魔数的“受载爪—闭合爪运动竞态守卫（Gripper Transfer Race Guard）”，作为可选通用开关供多夹爪机器人启用；
>   - **L3（策略观测契约升级）**：在通用观测中引入末端夹爪力/电流或短历史帧上下文（`n_obs_steps >= 2`），从感知层面彻底消除单帧位置观测的抓持状态歧义。

---

## 1. 为什么放弃 `6ba0f73` 的原双爪互锁实现

历史基线 `6ba0f73` 曾在 `shared/common/` 的 `transition_retiming.py` 中实现 `other_closing` 互锁，其条件直接写死了 `initial < 0.060 m`、`anchor[g] > 0.056 m`、`end < 0.068 m` 等常数：
- 这些数值直接绑定 Marvin 交接任务中 `60 mm` 宽的物块，违反 `AGENTS.md` §2.3–§2.4 关于 `shared/common/` 100% 机器人/任务无关的红线；
- 若换用 `40 mm` 方块、`90 mm` 工件或其他夹爪机构，硬编码阈值会直接失效或误锁正常释放；
- 实测 `marvin_sim/handover` 掉块的直接根因也并非左爪早松（`liveSync_4157` 已完整通过 `left_release` 与 `right_airborne_stable`），而是 `sample_filter` 误砍交接稳态样本 + 零方差视觉过拟合导致右爪误张开。

## 2. 后续期望落地：深层通用实现路径

### 2.1 L1：受载爪—闭合爪运动竞态守卫（零魔数、纯物理判据）

**适用前提**：任意具备 2 个及以上末端夹爪（`joint.unit == "m"`）的机器人，无需声明任务类型、物块尺寸或左右手角色。

**通用物理判据**（同时满足以下三条即判定存在“负载转移竞态”）：
1. **夹爪 `A` 处于受载夹持态**：
   - 不依赖物块宽度，只看物理阻挡特征：**闭合方向控制参考持续小于实测开度**（`q_ref[A] < q_meas[A] - load_gap_tol`，说明两指被物体顶住而产生夹持预载力），或直接消费底层通用接触/力矩反馈标志；
2. **另一夹爪 `B`（`B != A`）正处于闭合行进未稳态**：
   - 本执行窗口目标要求 `B` 显著闭合（`q_target_end[B] - q_start[B] < -close_step_tol`）或继承速度仍在明显闭合（`v_anchor[B] < -close_vel_tol`）；
3. **本窗口要求 `A` 同步释放**：
   - 预测窗口要求 `A` 显著张开（`q_target_end[A] - q_start[A] > +open_step_tol`）。

**守卫动作**：
- 仅将 `A` 的释放延迟一个窗口（本窗维持 `A` 的当前闭合参考不变，不改 `B` 的闭合轨迹），并发出结构化审计事件；下一窗口若 `B` 已停止闭合（进入受载稳态），`A` 自动放行释放。
- **单手任务零影响**：如 Panda 堆叠中另一只手无闭合运动，判据 2 恒为假，零触发、零侵入。

### 2.2 L3：感知与策略观测层根治（跨阶段架构升级）

单帧关节位置观测 `observation.state = qpos` 在物理上存在固有的信息欠缺：当夹爪经过某一开度时，仅凭单帧 `qpos` 无法区分“空抓闭合途中”与“已接触物体并施力夹稳”。

**长期通用升级方向**（涉及观测契约变更与数据集重采，须经用户确认后实施）：
1. 在 `RobotState` 与观测 Schema 中可选暴露通用末端负载特征（如夹爪力矩/法向接触力或驱动电流）；
2. 在策略端支持短历史观测帧堆叠（`n_obs_steps >= 2`）或引入关节速度特征，让策略自身从时序动态中区分“运动中”与“已稳态夹持”，从而彻底摆脱运行侧启发式守卫。
