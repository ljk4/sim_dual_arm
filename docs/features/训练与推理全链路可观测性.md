# 训练与推理全链路可观测性及插件解耦

本文档汇总本轮完善的三端工程体验、训练/转换契约防护与仿真端通用插件解耦能力。

> **状态区分（文档内标注）**
> - **本轮已落地**：后端启动就绪标准输出反馈、并行采集与并行推理 ETA 剩余时间显示、三端统一 `_YYYYMMDD_HHMMSS` 时间戳日志与防重名自增后缀、数据集转换前置目标目录拒覆盖检查、训练期视觉骨干分组学习率 `training.lr_backbone`、以及仿真端 `common/plugins.py` 约定式动态插件发现。
> - **后续期望落地**：并行采集/推理单局失败原因实时聚合面板、以及面向新机器人接入的一键脚手架校验命令。

---

## 1. 全链路可观测性与脚本体验

### 1.1 后端启动就绪与关闭反馈
- **所属模块**：`simulation/mujoco/src/robot_backend_sim/common/ros/backend_cli.py`、`simulation/mujoco/scripts/backend.sh`（及其轻量包装 `simulation/mujoco/scripts/{teacher,inference}_backend.sh`）。
- 后端完成 ROS 节点初始化、首帧物理步进与渲染就绪后，向运行目录写入 `ready.json` 并向标准输出明确打印已启动状态、运行目录、日志目录及监听命名空间；收到退出信号安全收尾后打印已停止摘要，消除用户与自动化编排启动后端后无法判断就绪时刻的盲等。

### 1.2 并行采集与并行推理 ETA 进度显示
- **所属模块**：`runtime/ros2/ros/dual_arm_runtime/dual_arm_runtime/offline/{collection/record_pool.py,evaluation/inference_worker.py}`（宿主机并行入口为 `shared/common/tools/host/{docker_pool,record_parallel,inference_parallel}.py`）。
- TTY 终端下使用原地刷新进度条并按已完成局数实时估算剩余时间（ETA `HH:MM:SS`），同时定期刷新已用时间，避免长时任务静默刷屏；非 TTY 场景仅输出关键阶段与最终汇总。

### 1.3 统一时间戳日志与可重复运行
- **所属模块**：`learning/lerobot/{scripts/server_policy.sh,src/dual_arm_learning/{cli.py,serving/cli.py,training/support.py}}`、`runtime/ros2/{scripts/client_{interactive,policy}.sh,ros/dual_arm_runtime/dual_arm_runtime/offline/collection/{record,record_pool}.py}`、`shared/common/tools/host/{record_parallel,inference_parallel}.py`、`simulation/mujoco/{scripts/{backend,teacher_backend,inference_backend}.sh,src/robot_backend_sim/common/ros/backend_cli.py}`。
- 所有脚本默认生成的 `run-id` 与日志文件名统一以人类可读时间戳 `_YYYYMMDD_HHMMSS` 结尾；若同秒内重复触发，自动追加 `_2`、`_3` 后缀，确保任意入口均可安全重复运行而不覆盖或因目录冲突失败。

## 2. 数据转换与训练契约防护

1. **数据集转换前置拒覆盖（Fail-Fast）**：
   - `learning/lerobot/src/dual_arm_learning/dataset/dataset.py`（`_validate_output_target`）在读取与校验源录制目录之前即检查目标输出目录是否已存在，若已存在立即抛出 `ExportError`，避免耗费数分钟逐帧校验后才失败。
2. **视觉骨干分组学习率（`training.lr_backbone`）**：
   - `learning/lerobot/src/dual_arm_learning/{config.py,training/{support,engine}.py}` 支持在 `act_training.yaml` 中独立配置 `training.lr_backbone`（不得高于主学习率 `lr`，默认与 `lr` 一致），并在 `training.model_ready` 事件与 `training_args.yaml` 中完整落盘。

---

## 3. 仿真端约定式动态插件解耦

- **所属模块**：`simulation/mujoco/src/robot_backend_sim/common/plugins.py`、`common/physics/{assets,robot_adapters}.py`、`common/config/scene_loader.py`、`common/tasks/registry.py`。
- 机制：`common/plugins.py` 动态扫描 `robot_backend_sim/<robot-id>/plugin.py`（导出 `ROBOT_PLUGIN`，并声明该机器人关联的任务插件描述符 `tasks`），再由 `common/tasks/registry.py` 按 `(assembly, task_type)` 双键延迟创建任务插件，彻底消除 `common/` 内对具体机器人名或任务名的硬编码。新增机器人或任务只需按平级 `<robot-id>/` 与 `<robot-id>/<task-id>/` 结构放入插件模块并注册描述符，无需修改 `common/` 任何调度文件。
