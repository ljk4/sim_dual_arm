# 静止锚点精准过滤（Sample Filter）

本文档定义训练数据集中静止冗余帧的精准抽稀规则与演进边界，目标是**仅抽稀无用空等静止帧，完整保留物理必需的稳态保持与阶段/门控切换边界**。

> **状态区分（文档内标注）**
> - **本轮已落地**：通用过滤引擎支持双边界保护（`phase` + `gate` 切换）与可选门控白名单 `static_runs.only_gate_states`；两方案 `act_sample_filter.yaml` 统一收敛为 `min_frames: 15`、`edge_frames: 5`、`interior_stride: 5`、`phase_boundary_frames: 5`、`only_gate_states: [WAITING_FOR_FEEDBACK]`。
> - **后续期望落地**：在 Teacher 示教采集侧压缩航点间冗余 `WAITING_FOR_FEEDBACK` 等待时长，从数据源头缩短 60 步动作标签内部的前导静止前缀。

---

## 1. 功能定位与职责边界

- **所属层**：
  - 通用过滤引擎：`learning/lerobot/src/dual_arm_learning/sample_filter.py`、`sample_filter_rules.py`（100% 方案无关）；
  - 方案规则参数：`shared/scenarios/<robot-id>/<task-id>/configs/learning/act_sample_filter.yaml`。
- **作用边界**：
  - `sample_filter` **不改写 Parquet / MP4 数据集本身**，仅在 `full` 模式训练启动时在内存中计算 `SubsetRandomSampler` 的保留帧索引；`smoke` / `overfit` 模式及验证集永不过滤。
  - 修改过滤规则后**无需重新转换 LeRobot 数据集**，直接重训即可生效。

---

## 2. 本轮已落地实现

### 2.1 全轴同时静止边判定（`_static_edges`）
仅当相邻两帧 `i -> i+1` 上**全部受控臂关节与夹爪同时静止**时才记为静止边：
- 臂关节：`|Δmeasured| <= max_step_rad`、`|Δapplied| <= max_step_rad`、实测/指令速度 `<= max_velocity_rad_s`；
- 夹爪：`|Δmeasured| <= max_step_m`、`|Δapplied| <= max_step_m`、实测/指令速度 `<= max_velocity_m_s`。

### 2.2 精准区分“无用空等”与“物理稳态”
1. **长度门槛高于必需物理稳态时长**：
   - `static_runs.min_frames: 15`（`0.75 s` @ 20 Hz），严格高于 `0.5 s`（10 帧）的常规抓取/交接物理稳态要求。
2. **门控状态白名单（`static_runs.only_gate_states`，可选）**：
   - `sample_filter_rules.py` 新增可选校验字段 `only_gate_states: tuple[str, ...] | None = None`（非空且无重复）。
   - 配置为 `[WAITING_FOR_FEEDBACK]` 时，长静止段内部**仅当该帧 `gate_state` 命中白名单时才允许被抽稀**；`TRACKING` / `HOLDING` 物理运动与稳态保持帧 100% 保留。
   - 若规则省略该字段（`null`），退回纯长度+步长抽稀，兼容无门控事件日志的数据集。
3. **双边界保护（`_protections`）**：
   - 保护整局首尾各 `episode_boundary_frames: 5` 帧；
   - 同时保护 **`phase` 切换与 `gate` 切换**前后各 `phase_boundary_frames: 5` 帧，避免丢失进入/离开等待段或抓取/释放瞬间的关键样本。
4. **温和抽稀步长**：
   - `edge_frames: 5`、`interior_stride: 5`，在不破坏时序分布的前提下仅压缩无用等待段内部帧。

### 2.3 验证测试
- `tests/unit/test_learning_sample_filter.py` 覆盖真实规则加载、`TRACKING` / `HOLDING` 物理稳态保留、`gate` 切换边界保护、`WAITING_FOR_FEEDBACK` 内部抽稀，以及省略 `only_gate_states` 的默认行为。

---

## 3. 后续期望落地

1. **Teacher 采集侧源头减等**：采样掩码仅筛选训练锚点，不改变未来 60 步标签 `action[t : t+60]`；后续可在各方案 Teacher 门控与规划中去除非必需的航点停顿，仅保留评价器所需的物理稳定窗口。
2. **数据质量审计报表增强**：在采集与转换日志中统计各 `gate_state` 的帧占比与静止段分布，辅助评估数据效率。
