# 静止锚点精准过滤（Sample Filter）

本文档定义训练数据集中静止冗余帧的精准抽稀规则与演进边界，目标是**仅去除无用空等静止帧，绝不误伤物理必需的稳态保持与阶段切换**。

> **状态区分（文档内标注）**
> - **本轮落地**：在学习端采样掩码层（`sample_filter.py` / `sample_filter_rules.py`）恢复 `gate` 状态切换保护、新增通用可选字段 `only_gate_states`（仅对指定空等门控状态如 `WAITING_FOR_FEEDBACK` 抽稀），并将两方案 `act_sample_filter.yaml` 的 `min_frames` 提高至 `15` 帧（`0.75 s`）、`edge_frames: 5`、`interior_stride: 5`、`phase_boundary_frames: 5`，避免误伤 `0.5 s` 物理稳态持物期。
> - **后续期望落地**：在 Teacher 示教采集侧压缩航点间冗余 `WAITING_FOR_FEEDBACK` 等待时长，从数据源头缩短 60 步动作标签内部的前导静止前缀（仅保留任务评价器物理必需的稳态持物时间）。

---

## 1. 功能定位与问题背景

- **所属层**：
  - 通用过滤引擎：`learning/lerobot/src/dual_arm_learning/sample_filter.py`、`sample_filter_rules.py`（100% 方案无关）；
  - 方案规则参数：`shared/scenarios/<robot-id>/<task-id>/configs/learning/act_sample_filter.yaml`。
- **作用边界**：
  - `sample_filter` **不删改 Parquet / MP4 的时间轴**，只在 `full` 模式训练时在内存中生成 `SubsetRandomSampler` 的保留索引。
  - 此前 `min_frames: 6`（`0.30 s`）、`interior_stride: 10` 且移除 `gate` 边界保护的配置存在严重误伤：将评价器硬要求的 `0.5 s`（10 帧）持物稳态（如 `left_grasp`、`dual_hold`、`left_release` 后的右独持）与 `1.2–1.5 s` 的无用门控空等一并抽稀，导致 `marvin_sim/handover` 关键交接段损失 40%–55% 训练样本，闭环出现右臂位姿残差与掉块。

---

## 2. 本轮落地实现

### 2.1 静止边判定（`_static_edges`）
仅当相邻两帧 `i -> i+1` 上**全部受控臂关节与夹爪同时静止**时才记为静止边：
- 臂关节：`|Δmeasured| <= max_step_rad`、`|Δapplied| <= max_step_rad`、实测/指令速度 `<= max_velocity_rad_s`；
- 夹爪：`|Δmeasured| <= max_step_m`、`|Δapplied| <= max_step_m`、实测/指令速度 `<= max_velocity_m_s`。

### 2.2 精准区分“无用空等”与“有用稳态”
1. **长度门槛高于必需物理稳态时长**：
   - 将 `static_runs.min_frames` 设为 `15` 帧（`0.75 s`），严格大于 `0.5 s`（10 帧）的常规抓持/交接稳态判定窗口，确保短稳态段整体保留。
2. **门控状态语义限定（`static_runs.only_gate_states`，可选）**：
   - `sample_filter_rules.py` 新增通用可选字段 `only_gate_states: tuple[str, ...] | None = None`。
   - 当配置非空（例如 `["WAITING_FOR_FEEDBACK"]`）且事件日志提供了帧级 `gate_state` 时，静止段内部**仅当该帧属于 `only_gate_states`（明确的无用等待门控）时才允许被抽稀**；处于 `HOLDING` / `TRACKING` 物理稳态保持期的帧一律保留。
   - 若某规则未配置 `only_gate_states`（保持 `null`），则退回纯长度+步长抽稀，兼容无门控事件日志的场景与合成单测。
3. **双边界保护（`phase` + `gate`）**：
   - `_protections()` 同时保护整局首尾（`episode_boundary_frames: 5`）以及 **`phase` 切换与 `gate` 切换**前后各 `phase_boundary_frames: 5` 帧，避免在状态进入/退出临界点丢样本。
4. **温和抽稀步长**：
   - `edge_frames: 5`、`interior_stride: 5`，在不破坏训练分布均衡的前提下压缩无用空等占比。

---

## 3. 后续期望落地

1. **Teacher 采集侧源头减等**：由于采样掩码不改变 60 步未来标签 `action[t : t+60]`，真正要让模型不再学出 `1.0–1.5 s` 的等待前缀，需在各方案 Teacher 规划/门控阶段去掉非必需的航点停顿与空等窗口（仅保留物理稳定检查所需的最短驻留时间）。
2. **数据质量审计报表增强**：在采集与转换日志中统计各 `gate_state` 的帧占比，便于评估采集效率与空等比例。
