# 多轴协同过渡重定时

本文档定义策略执行窗口在提交给底层有界跟随器前的运动学可达包络检查与同臂多轴等比例协同重定时机制。

> **状态区分（文档内标注）**
> - **本轮已落地**：在 `RobotProfile` 派生与机器人类别绑定的 `coordinated_axis_groups`（同一 `<prefix>_joint*` 旋转关节组成协同轴组），通用重定时层（`transition_retiming.py`）对超限机械臂按组内最受限轴比例统一缩放位移，消除单轴独立裁剪导致的末端笛卡尔偏航；移除通用层硬编码夹爪关节名。
> - **后续期望落地**：在 `RobotProfile` JSON Schema 中支持显式声明自定义 `coordinated_axis_groups`（兼容非 `<prefix>_joint*` 命名拓扑的多臂/移动底座机器人）。

---

## 1. 功能定位与归属边界

- **跨端契约层**：`shared/common/python/contracts/src/robot_contracts/models.py`（`coordinated_axis_groups()` 与 `RobotProfile.coordinated_axis_groups`）。
- **通用算法层**：`shared/common/python/trajectory/src/robot_trajectory/transition_retiming.py`（`reachable_bounds()`、`_stop_bounds()`、`retime_action_window()`），100% 方案无关，仅依赖 `JointSpec`、加速度限值、跟随偏差预算与外部传入的 `axis_groups`。
- **运行端调用点**：`runtime/ros2/ros/dual_arm_runtime/dual_arm_runtime/chunk_stream.py`（`PolicyStreamRunner._retime()`），仅对策略来源生效，Teacher 示教流不执行重定时。

## 2. 本轮已落地实现

### 2.1 机器人协同轴组派生（`coordinated_axis_groups`）
- 按 `JointSpec.unit == "rad"` 且命名匹配 `<prefix>_joint<n>` 的前缀自动分组（例如双臂机器人自动形成左臂 7 轴组与右臂 7 轴组）；
- 夹爪等线性独立轴（`unit == "m"`）不编入臂协同组，保持独立重定时。

### 2.2 触发条件与可刹停包络
1. **单轴可达包络（`reachable_bounds`）**：基于锚点继承位置/速度 `(q0, v0)` 及 `JointSpec.max_velocity`、`max_acceleration`，计算选中窗口内每个时间点 `t` 的物理可达上下界并与关节硬限位求交。
2. **触发判定**：当某轴预测目标超出可达包络的偏差 `excess > budget`，或直线过渡相对原目标的偏差 `line_excess > 0.90 * budget` 时触发重定时。
3. **可刹停终点裁剪（`_stop_bounds`）**：对终点超出窗口末可达范围的旋转轴，额外与窗口末零速可刹停包络求交得到 `clamped_end`，防止非最终块在交接点遗留过大未减速速度导致过冲。

### 2.3 同臂等比例协同缩放
- 若某协同轴组内存在被触发轴且任一轴终点被裁剪（`clamped_end != end`）：
  - 对组内所有发生位移的轴计算最大允许缩放比例 `scale = min(|clamped_end - q0| / |end - q0|)`；
  - 将整组活动轴的窗口终点统一缩放至 `q0 + scale * (end - q0)` 并沿可达包络线性过渡，严格保持关节空间运动方向一致。
- 独立轴（如夹爪）与未触发组不改动；每次重定时均通过 `follower.chunk_retimed` 事件记录原始与适配后的首末目标及原始越界量。

## 3. 验证测试

- `tests/unit/test_transition_retiming.py`：验证单轴直线重定时、反向减速切换、无越界直通、以及同臂协同轴组等比例缩放与独立轴零干扰。
- `tests/unit/test_follower_transition_retiming.py`：基于真实 Ruckig 规划器验证原始越界请求被拒收、重定时后请求可无违例执行。

---

## 4. 后续期望落地

1. **Profile 显式声明轴组**：允许在机器人 `profile.json` 中显式配置 `coordinated_axis_groups`，适配任意关节命名规范或躯干+双臂耦合拓扑。
2. **重定时频次健康监控**：在离线汇总报表中统计 `follower.chunk_retimed` 触发率与各轴缩放比例分布，作为模型平滑度与策略切换质量指标。
