只在隔离工作树实现，不 Git 写、不 Docker/网络/安装/宿主 venv/训练，不读历史和重复自审。主助手容器验收；修改完成立即摘要结束，不扩展其他端。

6. simulation/mujoco/docker/README.md、simulation/mujoco/scripts/README.md 同步说明通用资产变量、运行 ENV 位于安装后、真实 GPU 配置，无旧自定义字段承诺。本文追加实现/未测项。根规范与当前阶段/索引由主助手改，不扫改历史或其他端 Docker。

## 实现

- `simulation/mujoco/docker/Dockerfile` 将 `SIM_ASSETS_ROOT`/`SIM_ASSET_SUMMARY` 改为通用 `ASSETS_ROOT`/`ASSET_SUMMARY`，默认值保持 `/data/simulation/assets/mujoco_menagerie` 与 `/build/assets/panda.json`；`PROJECT_ROOT`、`BUILD_ROOT`、`DATA_ROOT`、`ROS_SDK_ROOT`、资产、MuJoCo 和 ROS 运行 ENV 移到 `pip install` 之后，安装层只保留基础 Python/pip/DEBIAN 设置和 venv `PATH`。单 `FROM`/`COPY`/`pip`、`requirements.lock`、`/opt/dependencies`、包版本和 hash 未变。
- `simulation/mujoco/scripts/run.sh` 同步两个资产变量名，所有命令分发和参数转发保持不变，不保留旧 `SIM_*` 名称、fallback 或别名。
- `simulation/mujoco/docker/docker-compose.yml` 删除 `PROJECT_COMPONENT`、`PROJECT_IMAGE`、`PROJECT_WORKSPACE_VERSION`、`PROJECT_REQUIRE_NVIDIA_RENDERER`；保留 service `simulation`、`SIM_IMAGE`、generic setup、ROS 网络、四个挂载、entrypoint 以及真实 `runtime: nvidia`/`gpus: all`。
- `infrastructure/scripts/check_dockerfiles.py` 对 `service_name == "simulation"` 直接要求 `runtime: nvidia` 与 `gpus: all`，不再读取已删除开关；现有有效 simulation fixture 补齐这两个字段，并增加缺 GPU、错误 runtime 的拒绝断言，其余 ROS/挂载/idle/宿主边界检查未变。
- 本项目 tests 内 15 个直接调用方仅把 `SIM_ASSETS_ROOT`/`SIM_ASSET_SUMMARY`/`SIM_ASSET_SOURCE` 字面改为 `ASSETS_ROOT`/`ASSET_SUMMARY`/`ASSET_SOURCE`，默认值和物理/控制断言未改；`test_environment_entry.py` 删除 setup fixture 中无用的 `PROJECT_COMPONENT`，并断言仿真 Compose 不含四个旧字段、资产 ENV 使用通用名。
- `simulation/mujoco/docker/README.md`、`simulation/mujoco/scripts/README.md` 同步通用资产变量、运行 ENV 后置和真实 GPU 配置说明，不再承诺旧自定义字段。
