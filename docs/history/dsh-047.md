# DSH-047：ACT 按仿真时间对齐的预测融合

## 证据与目标

用户当前要求解决推理问题并至少成功一次。DSH-045 的 1s 窗口已让机器人真实走到方块附近，但30401第8块右joint2偏差0.229rad被原0.15rad拒绝；在相同拒绝anchor缩短到2/5/10/15点也拒绝，不能只靠缩短窗口。主助手用已有8条真实预测，按仿真时间融合重算（不新推理、不推进物理）：8条均通过原参考/硬限位/偏差检查，第8条最大右臂偏差降至约0.103rad。此离线反例不能证明真实成功。

依据固定LeRobot ACT的 temporal ensemble 思路（https://github.com/huggingface/lerobot/blob/7e241bd630a3719a56157a497ce5d08f244784f1/src/lerobot/policies/act/modeling_act.py）：对同一未来时刻的历史预测作指数加权，较老预测保留动作块连续性。本项目查询间隔可能1s，不能直接调用假设每次仅前进一个50ms步的上游update，必须按绝对仿真时间对齐。不得重新训练、改模型bundle或放宽任何控制/夹爪准入/成功阈值。

## DSH 实现

1. 新增 components/learning/src/dual_arm_learning/act_temporal.py，职责单一、纯NumPy、无需ROS/Torch。维护每会话有界历史，完整块60x16、周期P=50ms。当前obs时间t，当前第i点绝对时间T=t+(i+1)P；历史obs时间s的第j点只在T=s+(j+1)P时贡献，且0<=j<60。权重w=exp(coeff*(t-s)/P)，对每个未来时刻独立归一化。正coeff偏向较老预测；默认试验0.01。只融合当前和历史真实预测，不从当前关节/真值/教师生成动作，不延伸或移动模型时间轴。历史超过3s或不能覆盖当前未来点的条目丢弃，最多60个条目；严格检查时间单调且同50ms格，不静默四舍五入/插值。初次只有当前预测时原样返回；尾部无旧预测时使用新预测。保留float64精度/有限性，形状恒60x16。

2. ActSettings 增加 model.temporal_ensemble_coeff 可选，缺省None关闭；非None必须finite、非bool、0<=coeff<=1。新增 configs/learning/act_policy_temporal.yaml，基于现有act_policy.yaml，仅新增此值0.01，旧默认配置不变。act_service/load_act_provider/ActProvider 显式传递参数，summary和配置日志注明。每个_Session独立历史，open新建/reset清空/close丢弃；ctx不匹配/时间倒退拒绝。时序融合全部16维同规则，不能覆盖左臂输出。

3. 先对新的完整raw_act做现有严格准入（机械臂越界拒绝、夹爪最多0.03m原规则），不能用融合掩盖原始越界或非法预测。仅被准入的新预测参与融合，输出融合后的60点。raw/admitted/correction原NPZ字段语义保持不变：raw_act=本次原模型输出；admitted=本次原预测经夹爪准入；correction=admitted-raw_act。开启融合时额外保存 execution_targets(最终传输60x16)、ensemble_counts(60)、history_observation_ids与history_observation_time_ns；记录融合enabled/coeff/贡献数/来源，原始张量不进普通日志。保存失败/日志失败/总predict deadline超时仍拒绝；历史只在完整合法预测成功后提交，禁止拒绝/失败污染历史。可用很小的具名预览结果+提交设计，不要通用事务框架。

4. 扩展 act_admission.save_prediction 的可选具名参数保存上述附加数组；关闭功能时保持既有文件和输出行为。沿用现有预算和原子保存，不产生多份重复大张量日志。ActProvider原有线程锁、warmup、单次完整predict_action_chunk、严格shape/finite和artifact约束继续有效。

5. 测试：新增 tests/unit/test_act_temporal.py 检查绝对时间对齐（跨100ms/1s间隔）、正系数偏向较老、逐时刻独立归一化/尾部仅新值、过期剔除/有界、初次不变、非法shape/finite/时间拒绝。扩展既有provider/contract测试检查关闭兼容、每会话隔离/reset清空、非法raw不被融合隐藏、NPZ语义和最终传输一致。只对需要的边界写有意义测试，不镜像实现。更新学习源码/配置目录README如需，阶段结果写本文件。

白名单：act_temporal.py、act_contract.py、act_provider.py、act_service.py、act_admission.py、configs/learning/act_policy_temporal.yaml、tests/unit/test_act_temporal.py、tests/unit/test_act_provider.py、tests/unit/test_act_contract.py、必要的 tests/unit/test_act_admission.py、相关2个目录README、docs/history/dsh-047.md、自有.build报告。禁止改ROS/proto/控制器/训练/模型/旧配置/评估判定，禁止Docker/仿真/联网/下载/安装/删除/Git add/commit。主助手执行真实GPU和物理验收。用PROJECT_PYTHON/PYTHONPATH运行目标纯测试，PROJECT_RUFF、git diff --check，报告真实结果与限制。实现限时15分钟，不为省步骤写隐式状态或难读大函数。

## 实现结果

- 新增 `components/learning/src/dual_arm_learning/act_temporal.py`：纯 NumPy 的
  `TemporalEnsemble`，按绝对仿真时间 `t + (i+1)*50ms` 对齐历史块，权重
  `exp(coeff*(t-s)/P)` 逐未来点归一化；严格检查 60x16/finite/整数时间/严格递增/
  同 50ms 格；只保留 3s 内且仍能覆盖当前未来点的条目，最多 60 条；提供
  `preview`（不改历史）与 `commit`（完整成功后才写入）两阶段入口。
- `ActSettings` 增加可选 `model.temporal_ensemble_coeff`（缺省 `None`，非 bool、
  finite、[0,1]）；新增 `configs/learning/act_policy_temporal.yaml`，只在旧
  `act_policy.yaml` 基础上增加该值 `0.01`，旧配置保持不变。
- `ActProvider` 每会话独立 `TemporalEnsemble`，`open` 新建、`reset` 清空、
  `close` 丢弃；上下文/时间不匹配拒绝。先对本次原模型输出执行既有机械臂硬限位
  与夹爪 0.03m 准入，只有 accepted 的本次预测才进入融合；NPZ 的 `raw_act`、
  `admitted`、`correction` 语义不变，融合开启时附加 `execution_targets`、
  `ensemble_counts`、`history_observation_ids`、`history_observation_time_ns`。
  历史提交位于 artifact、准入日志、deadline 检查之后，拒绝/失败不污染历史。
- `load_act_provider`、`act_service` 显式传递系数；summary、`act.model.ready`、
  准入/完成事件记录 enabled/coeff/贡献来源数，不记录原始张量。
- `save_prediction` 增加可选具名附加数组；未提供时 artifact 字段与旧行为完全一致。
- 同步更新学习源码与学习配置目录 README。

## 限制

- 本次只完成组件级实现与纯/离线测试，未执行真实 GPU 推理、MuJoCo 物理闭环或
  成功率验收；DSH-045 的 1s 窗口和本配置在真实场景是否成功仍需主助手验收。
