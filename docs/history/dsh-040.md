### 训练起点静止冗余筛选（DSH-040）

#### 目的与边界

该筛选只决定哪些**当前观察起点**进入训练采样器，属于重复起点降采样，不是物理成功条件，
也不声称静止阶段没有训练价值。它不会：

- 删除或重写源 Parquet、视频、时钟、`meta/stats.json` 或 manifest；
- 删除中间行后重新编号；
- 对 60 步未来动作标签再次筛选；
- 改变 `action_is_pad`、epoch 或验证集；
- 复制/重编码视频。

底层 `LeRobotDataset` 仍按原索引读取完整 60 步未来动作，采样器只把训练 query 索引限制为
mask 中的 `kept_indices`。

#### 规则

独立规则文件：`configs/learning/act_sample_filter.yaml`。

相邻帧边同时满足下列条件才标记为低运动：

- 右臂 7 个 rad 轴：实测位置和参考位置逐轴变化 `<= 0.001 rad`；
- 左右夹爪：实测和参考变化 `<= 0.0005 m`；
- 右臂：实测/参考速度在边两端均 `<= 0.01 rad/s`；
- 夹爪：实测/参考速度在边两端均 `<= 0.002 m/s`。

左臂不参与低运动判定，避免左臂待机把右臂运动平均掉。

连续低运动边组成静止 run：

- 少于 15 帧的 run 完整保留；
- 长 run 保留首尾各 5 帧；
- 内部从 `start + 5` 起每 5 帧保留一个 query anchor；
- 其余仅标记为 `redundant_static_anchor`。

保护规则优先于去重：

- episode 首尾各 5 帧；
- phase 切换点前后各 5 帧；
- 非 `TRACKING` gate、未知 phase、未知 gate 的帧全部保留；
- 若某 episode 最终训练起点少于 60，整条 episode 恢复原样，并在 mask 中记录
  `fallback: minimum_kept_frames`。

验证集从不筛选，固定 5 条、2160 帧。

#### 生成命令

```bash
PYTHONPATH=components/learning/src:libraries/run_logging/src:contracts/python/src:/path/to/lerobot-act-v0.6.1/src \
  .build/learning-dev-venv/bin/python tools/run/learning.py --project-root . filter-anchors \

  --dataset-root /path/to/panda_stack_learning_v1 \
  --select /path/to/formal-select.json \
  --output .build/reports/dsh-040/filter.json
```

输出已存在时命令拒绝覆盖。命令只读取正式数据，不写源数据目录。

#### Mask 绑定内容

`filter.json` 记录：

- 源 dataset manifest 路径与 SHA256；
- 训练/验证 Parquet 路径与 SHA256；
- 规则路径、规则 SHA256 和解析后的完整阈值；
- formal-select 路径与 SHA256；
- 每条训练 episode 的 original/kept/excluded index 列表、数量、source seed、原因；
- labels 文件 hash 与阶段/gate runtime events 文件 hash；
- 全局 phase/gate 的 source/kept/excluded 计数、减少率、fallback episode 列表；
- 自校验 `filter_digest`（排除生成时间，重算可重现）。

严格加载会拒绝：digest 不符、索引重复/越界/不排序、kept/excluded 不能划分 source、源
manifest/Parquet/labels/events/rule 任一 hash 改变、验证集被标记为筛选。

#### 训练集成

`TrainingConfig` 新增可选 `data.sample_filter`。未配置时行为与旧训练完全一致：

- 有效配置中不出现 `sample_filter: null`；
- 旧 checkpoint 的 `training_binding` 保持兼容；
- 验证 loader、模型、统计量、动作标签不变。

配置 filter 后：

- 仅 `full` 模式允许；smoke/overfit 显式拒绝；
- 训练 loader 使用 `SubsetRandomSampler(eligible_indices)`，不裁剪底层数据集；
- `training.model_ready` 和训练报告记录 source/eligible/excluded 帧数及 filter digest；
- checkpoint 额外绑定 mask 文件内容 SHA256，mask 内容改变后拒绝 resume；
- bundle 仅在配置了 filter 时附带 `metadata/sample_filter.json` 和可选追溯字段；旧 bundle
  结构不变。
