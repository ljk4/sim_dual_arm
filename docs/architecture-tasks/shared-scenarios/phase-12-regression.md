## 运行安排

先确认容器、挂载、磁盘和活动进程，选择未占用 domain 与命名空间。使用新诊断根、独立种子和小预算台账；正式 campaign 当前 50/50，不能直接复用其台账。每项运行设置次数或时间上界。

| 运行 | 需要得到的结果 |
| --- | --- |
| 两个隔离 worker 各一次 Teacher 尝试 | 实际调用新 Teacher 服务；所选 recipe 生效；domain、命名空间、输出和记录不串线；正常收尾 |
| 上述尝试中的一个完整 episode | 新反馈/轨迹类型可录制、导出和审计，得到真实任务、录制和质量结果 |
| 一次并行中断 | 从受支持的并行入口取消本轮运行，worker、backend 与锁正常收尾 |
| 真实现有 bundle 的一次有时间上界的 Policy 闭环 | scenario、有效 bundle、服务、动作与反馈链路一致，并记录实际任务结果 |
| 一个已选历史 episode | 用已验证的旧格式读取路径完成只读导出/审计，输出到新目录，与已有结果比较关键元数据及标签 |

前两项合用同一批运行，不另加一次重复单 worker 采集。中断优先合入这批运行；若会使正常收尾路径无法验证，则仅为中断补一个短尝试。已有真实运行覆盖同一路径时，复用它的结果。

历史读取使用已落地的专用旧格式路径或匹配的旧类型环境。当前入口明确拒绝旧格式是正确边界，但单独一个拒绝结果不等于历史导出已经验证。若受支持路径尚不能完成所需读取，修复具体缺口，不开发通用迁移工具。

Policy 使用原模型与控制参数；任务失败按实际结果报告。Teacher、真值或放宽门禁不替代 Policy 结果。必要的场景加载、渲染与服务验证随上述真实运行完成。

## 对照与收尾

比较实际生效的 Profile、观测/动作档案和关键配方参数。沿用已有身份值；路径变化、运行 ID 与明确的协议变化单独说明，不新建全树哈希证据。

确认本轮进程、worker 和锁已结束，正式数据及台账未改动。针对真实失败运行相应定位测试，避免失败后无差别重跑三端全量测试。

## 交付与已知问题
