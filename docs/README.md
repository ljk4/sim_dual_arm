# 文档索引

本目录维护两份总览正文：

- [项目状态](project-status.md)：总目标、约束、当前阶段、产物定位与下一步。
- [项目规范](standards.md)：目录、代码、文档、结构、接口、配置、日志与验收规则。

其余文档按用途组织：

| 目录 | 用途 | 文档粒度 |
| --- | --- | --- |
| [features/](features/README.md) | 详细说明功能、相关模块、流程与接口 | 一个功能一篇；当前仅有说明，具体内容后续讨论编写 |
| [experiments/](experiments/README.md) | 重要尝试、结果和可复用经验 | 用户主动提出收录，或助手建议并经用户同意后收录 |
| [history/](history/README.md) | 阶段计划、执行、返工和结果 | 每个 DSH 编号一份，按大阶段索引，附旧路径迁移表 |

原有阶段材料已归档，不在旧路径单独维护。功能文档描述当前能力，实践文档提炼
经确认的经验，历史文档保留当时的事实和决策；三者通过链接关联。

建议阅读顺序：根 [README](../README.md) → [项目状态](project-status.md) →
[项目规范](standards.md) → 按需要查阅功能、实践或历史索引。历史正文中的命令、
路径、预算和版本只反映当时状态，不能当作当前操作指南。
