# 重要实践与经验

本目录归档项目研发过程中具有长期参考价值的实验对比、故障定位与工程修复经验。无论实验成功、失败或推翻原有假设，重点在于记录**问题诊断逻辑、支撑证据以及经验的可复用边界**。

## 收录与维护准则

- **明确收录范围**：仅在用户指定或经确认具有普遍参考价值时建立正式条目，不堆砌日常调试流水。
- **命名与更新**：每篇文档聚焦一个核心问题或一组对照实验，命名为 `YYYY-MM-DD-<topic>.md`。同一主题的后续进展在原文上补充并注明更新日期。
- **推荐结构**：
  1. 问题描述、背景与核心结论。
  2. 实验条件、配置参数、随机种子与模型版本。
  3. 排查过程、根因分析与具体修复方法。
  4. 验收结果、数据/日志证据路径与适用边界。

历史条目记录当时的实验结果，证据路径中的数据、模型与构建目录不随源码保存；复现时应使用当前入口生成新的本机产物。
