# Marvin 双臂交接任务书

日期：2026-11-12。当前状态：已核对源 URDF 与现有接入代码；Marvin 模型、方案、任务和学习闭环尚未实现。本文档中的阶段、文件布局和接口名是实施要求，运行结果由各阶段交付记录提供。

## 交付目标

在 MuJoCo + ROS 2 + LeRobot ACT 的现有链路上新增 `marvin_handover` 方案，完成：

**左臂从桌面抓起长方块 → 空中交给右臂 → 左臂释放并退开 → 右臂将物块放入机器人右侧箱子 → 双手释放，物块稳定留在箱内。**

交付同时包含三项成果：

1. 程序示教通过物理接触完成整项任务，具备实测门禁、失败原因和停止收尾。
2. 使用本任务在仿真中实际采集的数据，完成导出、审计、转换、有限步数训练、新模型打包与后端执行冒烟。
3. 在接入过程中修复本次扩展暴露的耦合与职责问题，使 Panda 与 Marvin 通过各自方案选择运行，并保留 Panda 回归能力。

“实际采集”指 MuJoCo 中执行产生的记录。短训练用于验证数据到执行的链路，不要求其策略完成交接任务或达到任务成功率。物理示教成功、新模型执行冒烟、架构修复分别验收，三项均完成才结束本任务。

## 范围与实施约束

首版采用固定底座、固定桌面、固定物块初始姿态、固定交接区和箱位。动作保留现有 ACT 输入输出规格，详见 [P01](phase-01-model.md)；任务评价可以读取仿真真值，策略输入使用档案声明的 RGB 与实测机器人状态。

本次交付不包含真机驱动、力触觉策略、正式大规模训练或随机场景鲁棒性验证。源文件名中的 FT Sensor 不代表已经提供可读取的六维力传感器。

实现遵守仓库 [RULES.md](../../RULES.md)。保留已有修改、删除与历史产物，不自动暂存、提交或推送。修复服务于本次双机器人、双任务接入，不扩建插件框架或通用机器人平台。

## 扩展与分层要求

四端内部区分端内可复用机制、机器人/算法适配和任务专用实现，具体归属见[架构职责表](architecture.md)。跨端公共放 `shared/common/`；依赖 MuJoCo、ROS 或 ACT 的端内复用代码留在所属端。方案保存声明性选择、资产、档案与配方，业务实现继续归各端。

换机器人与换任务分别处理：前者集中调整机器人装配和执行适配，后者集中调整任务环境、Teacher、门禁与数据规则。已有能力支持的变化通过新增方案完成；新增能力的代码集中在对应适配/实现，保持机制的行为稳定。各阶段同时交付功能与必要边界修复，已有职责清楚的模块保留原位。
