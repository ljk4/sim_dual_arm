# 任务行为与物理判定

本文件定义首版任务的行为与验收语义。配置中的具体阈值由 P01～P03 测量后填写，任务插件按同一配方执行门禁与评价。

## 场景与坐标

- 底座固定，桌面承载一个刚性长方块；箱子开口向上，位于机器人自身右侧。机器人左右以基座坐标定义，并记录到世界坐标的变换，不以观察者或相机画面左右代替。
- 物块长度容纳两手在不同位置抓持，抓持间距给两个夹爪和腕部留出实际碰撞间隙。
- 首版固定物块初始位置与姿态、桌高、交接区和箱位。不同种子用于复位与记录标识；固定布局下的重复成功仅说明重复性。
- 箱体使用底板与四壁构成真实开口容器，避免单个碰撞凸包封住箱口。箱内尺寸按碰撞几何定义，足以容纳物块和放置过程中的手指。
- 初版选择物块在箱底放稳后松爪。运输与放置前，左臂已退至不会干涉右臂的姿态。

## 物理过程与阶段门禁

任务生命周期沿用 `IDLE / PREPARED / RUNNING / SUCCEEDED / FAILED`；下表是 `RUNNING` 内的行为阶段，写入任务指标与 Teacher 阶段字段。阶段名称为本任务约定，不能套用 stack 的阶段码。

| 行为阶段 | 动作与进入下一阶段的实测条件 |
| --- | --- |
| `left_approach` | 左臂张爪到预抓取位，右臂在避让位；TCP 误差与净空满足配方 |
| `left_grasp` | 左爪在目标抓持区闭合；两指同时接触同一目标物块，接触与相对运动稳定达到持续时长 |
| `left_lift` | 左臂抬起物块；物块离桌、左手持物稳定，持续达到离桌高度与时间门槛 |
| `handover_approach` | 左臂持物到交接区，右臂张爪接近第二抓持区；物块全程悬空，双臂和夹爪之间满足净空 |
| `dual_hold` | 右爪闭合；左右爪均对同一物块形成双指接触，右手接触与物块相对位姿稳定达到接稳时长 |
| `left_release` | 接稳门禁通过后左爪张开；确认左手已解除持物接触，右手仍持续持物稳定 |
| `left_retreat` | 左臂退开，右臂独立持物；左臂到达避让区，右手持物继续成立 |
| `right_transport` | 右臂运送到箱口上方；物块受右手支撑且不与桌、箱沿或机器人发生禁止接触 |
| `right_place` | 右臂将物块放到箱底；放置位、速度和允许的箱底接触满足条件 |
| `right_release` | 右爪张开并退出；确认双手已释放且均不再托住物块 |
| `stable` | 物块完全位于箱内，受箱底支撑，线/角速度低于阈值并持续达到稳定时长 |

所有阶段都有进入时间、等待上限和失败原因。阶段推进取决于观测事实，名义轨迹时刻仅决定期望动作。到达闭爪宽度、命令接受、轨迹完成或 Teacher 时钟经过某时刻均不能替代接稳门禁。

交接窗口从 `left_lift` 确认离桌起，到 `left_retreat` 完成止。窗口内物块不得与桌面、箱体或其他外物形成支撑接触。两手共持允许；双臂之间、夹爪之间和机器人与箱壁的碰撞仍须检测。目标物块的允许指面接触按阶段指定。

## 成功、失败与停止

成功要求保存上述完整阶段证据。最终包含判定将物块八个顶点变换到箱体坐标，全部落在配置的箱内边界和箱口以下；同时确认箱底支撑、双手释放以及连续稳定时长。使用物块中心点进入箱体不能代替完整包含判定。

稳定条件至少包含物块线速度、角速度、位置保持和双手无持物接触。临时接触丢失按配方的容忍时长处理，连续超限清零稳定计时或触发失败，不能跨越失稳区间累加时间。

| 失败场景 | 所属层与结果 |
| --- | --- |
| 左手未抓住、右手未接稳或阶段超时 | 任务插件停留在门禁，超过等待上限后失败；右手未接稳时左手保持持物 |
| 掉落、交接中借外物支撑、物块越界、禁止碰撞 | 任务插件记录对应物理失败并终止任务 |
| 关节/速度/轨迹约束、跟踪失败 | 控制层拒绝或停止，任务接收真实控制失败；保留首次停止原因 |
| 操作者中断、租约失效、服务异常、总预算耗尽 | runtime 发起有界停止并结束会话；结果记录为中断或失败，不记成功 |

首版失败后执行受控停止，保持当前夹爪目标，不自动张爪或执行未经验证的退避。停止、等待控制终态与资源收尾由控制层/runtime 完成；下一次尝试显式复位，任务插件清除旧门禁与计时。场景复位可以设置物体初态；执行期间通过接触运动改变物体，不使用焊接、绑定、吸附或直接改写物块位姿。

## 实测参数的落点

| 参数 | 确定阶段 | 唯一数值来源 |
| --- | --- | --- |
| 基座/世界坐标、桌高、物块尺寸质量、箱体内尺寸与位姿 | P01，P02 可达性确认后定稿 | 场景配方与模型资产 |
| 关节顺序、单位、有效限位、复位值、最大速度 | P01/P02A | Robot Profile；控制配方补充增益、加速度和跟踪等执行约束 |
| TCP、夹爪总开度映射、指面与接触对象绑定 | P01A/P02A/P02B | simulation 机器人适配与所选配方 |
| 双手抓持区、交接/避让/放置位姿及路径净空 | P02B | 任务/运动学配方，明确坐标系与单位 |
| 接触力门槛、持续时长、离桌高度、允许短暂丢失时间 | P02B/P03 | 通用接触判定参数归控制配方；阶段持物与交接门禁归任务配方 |
| 每阶段超时、总时限、最终稳定时间、线/角速度阈值、入箱余量 | P03 | 任务配方 |
| 可见性对象、阶段、像素与遮挡时限 | P04（已按真实渲染测量填写） | 本方案采集质量配方 `configs/runtime/experiments/handover_campaign.yaml` |

P04 的 6 条诊断示教只用于软件链路验证：每次 1120 条 20 Hz 标签，标签取观测后 50 ms 的实际受限执行参考；TaskState、接触、物块位姿和分割真值只用于门禁、阶段区间与质量/边界审计，不进入策略输入。

若同一字段被多个消费者使用，应从所属来源读取或准备时校验一致；binding 只选择文件。所有必需参数在相关阶段验收前填写，不能把空值或 Panda 数值作为默认值带入下一阶段。

完整任务总时限在 P03 根据 P02B 计划时长与门禁等待确定，并协调当前 runtime 的任务预算上限、窗口覆盖和停止余量。P05 的短时诊断预算使用独立配方，不能缩短完整示教的任务预算。
