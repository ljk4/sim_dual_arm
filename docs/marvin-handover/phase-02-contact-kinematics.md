# P02B 接触持物与双臂候选路径

状态：2026-11-12 已交付，实际结果见[交付记录](deliveries/phase-02b.md)。共持全过程与连续交接入箱物理诊断通过；P03 已交付，见[P03 交付记录](deliveries/phase-03.md)。

前置：P02A 的真实 Robot API 控制、反馈与停止通过。目标：取得可供 P03 直接复用的接触事实、任务目标与候选路径，确认本任务在当前物理模型上可执行。

实施顺序为：一致快照/接触事实 → 任务目标与空爪候选路径 → 左右独立抓取持稳 → 共持与带物候选路径 → 带物停止与回归。先取得必要 IK/净空依据，再经标准控制执行对应运动，不为持物诊断手写另一套轨迹。

## 交付结果与后续边界

已建立一致接触快照、机器人几何绑定、双臂 IK 与任务目标/路径模块。左右独立抓取各抬升约 `0.15 m`，双手共持抬升约 `0.08 m`；独立持稳、共持全过程相对位姿与稳态、带物停止均通过物理验收。共持步骤由任务侧 `tasks/handover/cohold.py` 根据固定实测抓持基准生成，并检查同一命令路径的协调误差与带物净空。

连续物理诊断复用 `plan_handover` 的同一条目标/路径链，经标准控制完成左手抓起、空中交给右手、左手释放退开、右手运输入箱并释放。最终验证物块实际八顶点位于箱内、箱底支撑、双手无接触及物块稳定；每个控制窗口与释放终态均通过。

上述诊断未接入任务生命周期、Teacher 或采集。P03 复用已有目标、路径和接触事实，增加任务编排、实测门禁、Teacher 接口和完整示教入口；阶段证据及历史尝试见交付记录。

## 接触与持物

1. 机器人适配提供左右爪、两指和测量地址，任务环境提供自由物块身份。通用接触代码产生每指对每物块的接触/力/运动事实，任务解释持物与外物支撑。
2. 双指同时接触同一目标物块才形成持物候选，结合相对运动和持续时长验证。单指擦碰、闭爪到限位或两指碰不同物体不算持物；允许两侧持有同一物块的事实同时成立。
3. 通过 P02A 标准控制执行左手抓起/持稳、右手独立持稳、短时双手共持和受控释放/停止。执行期间物块仅由接触运动改变，复位只发生在尝试边界。
4. 验证 P01 初始夹爪增益、力限、接触参数及卸载逻辑。稳定接触时参考开度变化和真实张爪分开处理，不通过扩大跟踪阈值、关闭超时或改写测量隐藏执行问题。
5. P02A 已有停止证据覆盖双爪张开的空爪状态。本阶段在真实持物中验证受控停止不主动松爪、物块持续受支撑且接触不被错误卸载；记录左右开度、每指接触、物块运动与控制终态。

独立持稳和共持稳态窗口均检查每侧物块相对 TCP 的位置/朝向变化，以及物块线速度/角速度，阈值取任务规划配方。共持全过程另以实际抓持建立时的物块/TCP 相对关系为基准，覆盖抬升执行和终端持稳；不能通过在抬升后重设基准消除执行中的滑移。所有诊断动作包括释放都核对实际控制终态。

物理真值由 simulation owner 线程捕获为一致、不可变快照，再交给规划/诊断消费者。IK 使用私有模型状态，runtime 不直接读取 MjData；诊断不得另起物理步进线程或绕过已有控制调度。

## IK、目标与路径的归属

- 通用求解/净空测量留在 simulation；机器人提供关节、TCP、有效限位及几何分组；handover 的抓持区、交接/避让/放置目标和允许接触归任务实现与配方。
- 本阶段即可建立任务的目标/路径生成模块，由诊断入口调用，P03 Teacher 直接复用。诊断入口只负责组装输入、调用和保存结果，不维护另一套抓取/交接轨迹生成逻辑。
- 将现有只求右臂、左臂冻结和 Panda 名称/限位假设与可复用求解机制分开。显式指定活动关节与双臂目标；顺序或联合求解采用当前任务能完成的最简单方案。
- 共持阶段两个抓持点和物块的相对关系保持一致；若两臂持续对抗，回到目标/时间配准与执行参数修复。
- 碰撞分组取实际模型绑定，包含 `Arm_L* / Arm_R*`，不依赖 left_/right_ 名称前缀或 source/target 物块名。使用 P01A 已验证的有效碰撞集合。
- 抓持朝向根据 Marvin TCP 与指面确定，不直接沿用 Panda 的向下朝向约定。运输与共持的净空检查纳入物块尺寸及其相对夹爪关系，不能只扫描空爪或让物块在规划副本中始终留在初始桌面。规划副本可计算假定持物包络，实际执行物块仍仅由接触运动改变。

## 路径与场景确认

从 P01 布局出发测量抓取区、双手抓持区、交接区、左臂退避位、箱口及箱底放置候选位。P01 ready 是渲染诊断位，不能当作已验证任务初态。

先验证关键姿态的 TCP 误差，再验证连接路径的限位、速度和连续净空；按阶段区分允许的物块指面/箱底接触与禁止碰撞。必要的物块/箱位、复位姿态、相机安装调整写回所属配方，并同步 profile/标定和受影响证据。候选目标位于机器人基座或明确声明的坐标系。

P00 记录的两条运动学测试/API 不一致在本阶段修正，保持不可能可见性与报告写入失败的原验证目的。反馈导出/MCAP 回归在具备 `robot_ros_support` 和 SDK 的 runtime 环境执行；learning 保持 ROS-free。

## 完成条件

- 左右独立持物、共持全过程及短时共持稳态分别满足接触、相对位姿和适用的运动阈值；诊断动作经标准控制执行，释放与停止终态符合预期。
- 抓取、交接、退手、入箱候选路径具有实际 IK/净空与受限执行依据。完整有门禁的换手任务留给 P03，不将候选路径通过写成任务成功。
- 目标/路径生成、接触事实与数值来源可被 P03 复用，机器人适配不依赖任务阶段。
- 相关 Panda/Marvin 运动学、接触、控制与停止回归通过；历史失败与新结果分别记录。
