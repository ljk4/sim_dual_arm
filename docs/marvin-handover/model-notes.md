按联动意图，公开控制量采用 14 个臂关节位置与 2 个夹爪总开度。MuJoCo 的 `nq/nv/nu` 受自由物块、手指建模及执行器方案影响，须从编译模型核对，不能由公开动作维数 16 推定，也不能复用 Panda 场景的固定模型尺寸断言。

源 URDF 两臂对应旋转关节给出相同限位，单位为 rad：

| 关节序号 | 下限 | 上限 |
| --- | --- | --- |
| 1、3、5 | -3.1067 | 3.1067 |
| 2 | -2.0944 | 2.0944 |
| 4 | -2.5307 | 1.0472 |
| 6 | -1.0472 | 1.0472 |
| 7 | -1.5708 | 1.5708 |

这 14 个关节的源速度上限均为 3.1416 rad/s。实际仿真运动可以选择更保守的有效速度；执行器增益、加速度、jerk 和跟踪阈值需要另行配置和验证，不能由源限位推断控制性能。

## 夹爪、坐标与源文件异常

四个滑动关节均为 `0～0.04 m`，速度上限写为 0。接入时将这一速度视为待补齐的源信息，在仿真配置中给出经验证的正速度；不直接生成速度为 0 的公开控制档案。

左侧两指轴向相反。右侧第 11 关节通过旋转实现对应方向，其原点包含 `y=1.793 m`，STL 与惯性原点也有较大局部偏移。完整组合后，该指惯性中心在夹爪父坐标系约为 `(0.0009007, -0.1432004, -0.0572298) m`，接近左侧对应手指。不能孤立清零关节原点；需要检查完整装配、实际指面和运动范围。

正向滑移使两指靠拢。公开总开度是指尖最小孔径在闭合轴上的投影，不能把两根滑动关节位移之和直接当成开度。源 mesh 指面有渐变，测量站点和名义 TCP 不代表覆盖全长的平行碰撞面。P02A/P02B 已验证开度、闭合量、速度符号和两指阻尼到前馈的映射。

仿真配方显式启用机器人自身重力补偿，自由物块仍受重力。有限接触面采用四维接触以提供扭转摩擦，椭圆摩擦锥、切向阻抗与 NoSlip 求解控制数值蠕滑；这些是仿真接触模型参数，不代表实物摩擦或真实控制器已标定。源资产、质量与惯量保持不变。

`Arm_R8_Joint` 是 fixed，却附有 `lower=1.5708, upper=-1.5708, velocity=0` 的 limit。它不属于可动关节，不据此生成自由度或控制限位。若导入器要求清理该字段，应在项目内转换步骤中明确处理并保留原资产。

URDF 的 mimic 表达源联动意图。P01A 已确认 MuJoCo 3.17 的 URDF 导入器为每侧生成一条 joint equality；P01 的手工 equality 是重复约束，已移除。保留的导入约束命名为 `Arm_*_finger_coupling`，写入经三态测量验证的 `solref`/`solimp`，编译模型 `neq=2`。固定末端结构和文件名中的 FT Sensor 不能当作可读六维力传感器。

碰撞排除已从 88 项收敛为每侧 `Arm_*5_Link`/`Arm_*7_Link` 一项：两者源凸包在复位和抽样可达位姿中永久重叠约 0.061 m，中间的 `Arm_*6` 使实际零件分离。其余同臂配对保持可碰，跨臂排除为零；P01A 用可达位姿验证了同臂、跨臂、手指和环境接触。底座仍仅渲染，适用边界见资产说明。
