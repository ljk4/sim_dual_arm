# P02 双臂运动与执行边界

前置：P01 完成。目标：通过现有控制链路独立控制两臂与夹爪，测量真实接触，确认交接与入箱路径可执行。

本阶段优先解除机器人执行耦合：I/O、夹爪驱动、TCP、接触语义与关节/几何绑定归机器人适配；步进、命令调度、通用受限控制和反馈机制留在 simulation。交接目标、持物门禁和成功判定归任务，机器人适配无需知道当前运行 stack 还是 handover。

## 具名 I/O 与控制接入

1. 沿 [架构接入缺口](architecture.md)中的 owner → I/O → controller 调用链接入 Marvin。两种机器人适配提供当前消费者所需的具名测量与目标写入能力；物理步进、线程归属和调度继续由现有 owner/control 持有。
2. 移除新机器人路径对 `isinstance(PandaIO)`、Panda 限位、固定指关节名、7/15 魔法索引和执行器量纲的依赖。需要的角色索引由新 profile/机器人绑定求出；协议仍保持 16 维，不借此改造任意自由度平台。
3. control、stream、follower 配方使用 Marvin 有效限位、速度、加速度、jerk、增益、跟踪阈值和超时。由 profile 读同名字段或准备时核对，避免在不同配置内维护互相矛盾的限位。
4. 保留输入有限值、连续轨迹约束、命令身份、租约、窗口/锚点和停止保护。写入 `ctrl` 或 SubmitFollower 接受仅代表提交；通过 RobotState 与执行反馈报告实测跟踪和终态。
5. 验证左右夹爪分别开合、左臂动而右臂保持、右臂动而左臂保持、两臂协调运动。夹爪闭合方向、总开度、速度和命令完成判定使用 Marvin 映射。

## 接触与持物事实

- 机器人适配提供两侧手指的 body/geom/关节与测量地址，场景提供自由物块身份。接触代码据此产生每指对每物块的接触、力和运动事实。
- 双指同时接触同一目标物块才形成持物候选；接触稳定还需物块相对夹爪运动及持续时间证据。机械手闭合到限位、单指擦碰、两指接触不同物体均不算持物。
- 保持“通用接触事实”与“任务交接门禁”分离。接触代码不能假设任意时刻只有一侧持物；共持期间两侧事实同时有效，支撑关系由任务评价。
- 检查稳定两指接触时参考宽度变化的处理，以及真实卸载/张爪时接触状态变化。保留正确跟踪保护，不通过屏蔽超时或放宽阈值替代执行修复。

## 双臂 IK、路径与净空

1. 将现有只求右臂、左臂冻结的运动学路径与 Panda 限位剥离。求解器按所选机器人绑定获取两臂关节、TCP、有效限位和活动集合，任务构造抓取/交接/放置目标。
2. 顺序求解与双臂联合求解均可，首版选择能完成本任务的最简单方案。两臂共持阶段保持物块与两个抓持点的相对约束，不能分别求出两个互相拉扯物块的独立轨迹。
3. 由实际模型绑定建立机器人自碰、双臂互碰、机器人与桌/箱/物块的碰撞集合。确认保留原名 `Arm_L* / Arm_R*` 的几何也参与检测，避免沿用 left_/right_ 前缀分类而漏检。
4. 先验证 TCP 目标误差，再验证连接路径的净空和连续限位。只检查关键点可达不足以证明两臂交叉、退手和过箱沿的整条路径可行。
5. 确定抓取区、两个物块抓持区、空中交接区、左臂退避位、右臂过箱口与箱底放置位。参数写回所属配方，并记录单位、坐标系、允许接触阶段。

## 验证与完成条件

取得以下实际结果及相关回归，具体次数按暴露问题确定，不重复运行已由后续完整任务覆盖的检查：

- 两臂与夹爪的命令/实测映射一致，正常运动完成，超过有效限位的请求被拒绝。
- 左手实际抓起物块并短时持稳；右手在独立抓取诊断中持稳；双手共持时不出现持续对抗、物块瞬移或明显接触穿透。
- 双臂交接、左手退开和入箱候选路径具有实测 IK/净空依据，并能通过受限执行到达相应姿态。
- 运行中停止和跟踪失败能得到真实原因、控制终态与有界收尾；停止不自动松开持物夹爪。
- Panda 的 I/O、控制、接触和运动学相关测试通过；受改动影响的实际运动对照仍成立。
- owner/controller 通过所选机器人能力工作，适配选择集中在装配入口；通用执行循环不增加 Marvin/handover 专用动作分支，机器人适配不反向导入任务插件。
