# JSON Schema 契约

本目录直接存放机器人 Profile、观测、动作、Episode Manifest、运行事件和运行状态的 JSON Schema。校验拒绝未声明字段。

- Schema 仅定义文档结构与基础类型约束；关节顺序、相机命名、物理单位与跨字段语义由方案 [`profiles`](../../../scenarios/marvin_sim/stack/README.md) 与 [`robot_contracts`](../../python/contracts/src/robot_contracts/README.md) 联合校验。
