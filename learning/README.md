# 学习与策略服务端（Learning）

本目录按机器学习框架组织数据集构建、模型训练与策略推理服务实现。当前唯一实现为基于 LeRobot 的 ACT（Action Chunking with Transformers）框架（[`lerobot/`](lerobot/README.md)），全程保持 ROS-free。当前 Panda 堆叠任务的数据集、训练与服务配方见 [`shared/scenarios/panda_stack/`](../shared/scenarios/panda_stack/README.md)，公共 Policy 契约见 [`shared/common/interfaces/policy/`](../shared/common/interfaces/policy/README.md)。
