# config

声明式配置及校验。

模块：`backend_config.py`、`camera_config.py`、`follower_config.py`、`kinematics_config.py`、`marvin_scene_config.py`、`motion_config.py`、`panda_scene_config.py`、`scene_loader.py`、`stream_config.py`。

`scene_loader.py` 按 `robot.assembly` 选择 `panda_scene_config.py` 或 `marvin_scene_config.py`。

本子包不依赖 ROS。

目录导航：[上级目录](../README.md)
